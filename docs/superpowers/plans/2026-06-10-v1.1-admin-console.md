# v1.1:管理员面板简化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Console 从"全员自助门户"简化为**纯管理员面板**:成员不登录、只持 Key;管理员为成员签发 Key(一步带预算)并一键复制接入说明;保留团队层做分组与总额度。

**背景(用户需求原话):** ① 不需要用户面板,只要管理员面板配置模型 Key(仅 OpenAI/Anthropic);② 成员不登录,拿 Key + 各平台使用说明即可。

**架构影响:** 网关/worker/计费/审计**零改动**(Key 鉴权与 Console 账号无关)。数据库 schema 零改动(users/team_members 保留,语义收窄:users=管理员账号;team_members 不再使用但不删表)。成员 Key 的归属模式:`ownerType=team`(消费上卷:key 预算 → team 预算两层),`name`=持有人备注。

**裁剪原则:** 隐藏而非删除(导航与入口移除,路由保留 requireAdmin 防直接访问;未来要恢复零成本)。
